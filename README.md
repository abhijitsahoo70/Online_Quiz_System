# 🎓 Online Quiz System

A modern **Online Quiz System** built using **Python, Flask, SQLite, HTML, CSS, JavaScript, and Jinja2**. This web application allows students to register, take quizzes on multiple subjects, view scores, download certificates, and track their performance through an intuitive interface. It also includes an admin panel for managing questions and monitoring student activity.

# 💻 How to Run Locally

## 1. Clone the Repository

```bash
git clone https://github.com/abhijitsahoo70/Online_Quiz_System.git
```

## 2. Open the Project

```bash
cd Online_Quiz_System
```

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## 4. Start the Application

```bash
python app.py
```

## 5. Open Your Browser

```
http://127.0.0.1:5000
```
